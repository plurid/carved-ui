Rebuild Carved for React 19. Every surface is cut into one material and lit by one light: hover and press deepen a control's carve, tones are inlaid as polished mineral (each preset with its own accent: silver, lapis, glacier, indigo or gold leaf), and only moving pieces rise. Keyboard focus lights a control's own edge, and links run along an engraved groove. A new theme engine turns one colour into six OKLCH depths with guaranteed contrast for text, edges and inlays. Components are built on React Aria, composed for the common case with their parts exported, and styled with plain CSS in cascade layers. The catalogue covers fields, dates and times, colour, files with a list that shows their progress, collections including a data table and tree, overlays including a command palette, navigation and feedback. `CarvedProvider` takes your router's `navigate`, so links inside navigate without reloading. See the migration guide.
