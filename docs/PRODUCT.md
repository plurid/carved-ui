# Product context

Carved UI is a React-first component system for developers building web applications. Its recognizable mechanism is six levels of recessed, carved surfaces, generated from named themes or a custom opaque color.

The modernization is a clean v1 API break that retains the React npm identity. The active scope is a production core catalog, a framework-independent token/theme package, an executable Storybook laboratory and editable application patterns. HTML, Vue and the original design demo are archived. A full enterprise toolkit and source registry are deferred.

Success means a reproducible modern pipeline, minimal root files, readable compositional APIs, accessible proven interactions, independent scoped themes, server-safe rendering and verified package consumers. React 19, TypeScript and semantic CSS variables are the chosen public foundation. Developers should be able to inspect source and meaningful states without navigating shallow wrapper files.

Confirmed direction: evolve Carved's material identity, preserve seven named presets and runtime custom-color generation, package the stable core, and keep higher-level examples editable in the consuming application. Tooling/configuration belongs below the root; README, license, manifests, lockfile and gitignore are the only root files.
