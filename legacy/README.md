# Archived implementations

`html`, `vue`, and `design` preserve the original inactive sources. They are excluded from pnpm workspaces, builds, tests and releases. Their historical READMEs and dependencies describe the old project, not the current supported setup.

Use `packages/react` and `apps/storybook` for active development. The old React implementation can be read in Git history. Historical design assets are preserved in `docs/assets/legacy`.
